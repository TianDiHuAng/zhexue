# 中外哲学思想脉络库

一个纯静态、零 JavaScript 的中外哲学资料库：中国 6 个时期 + 西方 8 个时期，**313 位哲学家**、**344 个核心概念**、**112 场重要争论**、**43 个流派**、**322 部经典著作页**、**40 篇比较视野**，共 **1105 个页面**、**28132 条内部链接（0 断链）**、**396 条来源（396 条实开核验，100%）**。

- 打开方式：直接双击 `site/index.html`（可离线，无外部依赖）
- 数据层：`data/china/*.json`、`data/west/*.json`、`data/schools.json`、`data/works.json`、`data/comparative.json`
- 校验器：`tools/check.py`（字段、年份、来源、双源、引文出处、SVG 越界等 20 条规则）
- 事后查重：`tools/precheck_src.py`（来源 id 存在性 + 著作标题规范化/别名查重）
- 生成器：`tools/gen_site.py`（JSON → 静态 HTML）
- 链接核验：`tools/check_links.py`（28132 条内部链接，0 断链）

## 页面类型

| 类型 | 结构 |
|---|---|
| 哲学家页 | 生卒与时代背景 / 核心问题 / 论点（前提→推理→结论）/ 著作与推荐版本 / 影响链 / 批评与回应 / 常见误解 / 一图（内联 SVG）/ 待核实 |
| 概念页 | 定义 / 在不同哲学家那里的用法差异 / 一个具体例子 / 相关概念 |
| 争论页 | 问题是什么 / 各方立场及理由 / 争论的焦点 / 至今是否有定论 |
| 流派页 | 核心主张 / 代表人物 / 兴起与衰落的原因 / 常见误解 |

另有中国与西方哲学时间线、哲学家/概念/争论/流派四个索引、思想谱系总图（纯 SVG）、来源列表（三态核验标注）。

## 体例

- 每条论点、批评、引文、立场都标注 **原文**（原典有明确文本依据）或 **后人解读**（后代注疏与研究者的解释框架）。
- 引文只取能定位到篇目者，单条不超过一两句；查无出处的「名言」一律不用。
- 每条内容至少两个独立来源互证，不足者标「待核实」并写明待核内容。
- 有实质争议处并列各方说法与依据，不替读者下结论，不贬抑任何一派。
