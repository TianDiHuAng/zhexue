# 中外哲学思想脉络库

一个纯静态、零 JavaScript 的中外哲学资料库：**中国 7 个时期 ＋ 西方 8 个时期 ＋ 印度 1 个单元**，**326 位哲学家**、**462 个核心概念**、**127 场重要争论**、**49 个流派**、**750 部经典著作页**、**193 篇比较视野**，共 **1749 个页面**、**54727 条内部链接（0 断链）**、**431 条来源（431 条实开核验，100%）**。

> 数字口径：以 `coverage.json`（由 `tools/gen_state.py` 生成）为准，本页数字随每轮重建同步。

- 打开方式：直接双击 `site/index.html`（可离线，无外部依赖，无 JavaScript）
- 数据层：`data/{china,west,india}/*.json`、`data/schools.json`、`data/works.json`、`data/comparative.json`
- 校验器：`tools/check.py`（字段、年份、来源、双源、引文出处、SVG 越界、概念层级成环、关系类型白名单等 22 条规则）
- 事后查重：`tools/precheck_src.py`（来源 id 存在性 + 著作标题规范化/别名查重）
- 生成器：`tools/gen_site.py`（JSON → 静态 HTML）
- 链接核验：`tools/check_links.py`（54727 条内部链接，0 断链）

## 页面类型

| 类型 | 结构 |
|---|---|
| 哲学家页 | 生卒与时代背景 / 核心问题 / 论点（前提→推理→结论）/ 著作与推荐版本 / **影响链（带关系类型：承继·批驳·私淑·同门相诤）** / 批评与回应 / 常见误解 / 一图（内联 SVG）/ 待核实 |
| 概念页 | 定义 / 在不同哲学家那里的用法差异 / 一个具体例子 / **概念的层级（上位·下位）** / 相关概念 |
| 争论页 | 问题是什么 / 各方立场及理由 / 争论的焦点 / 至今是否有定论 |
| 流派页 | 核心主张 / 代表人物 / 兴起与衰落的原因 / 常见误解 |
| 著作页 | 文本结构 / 核心论证 / 关键段落 / 版本与推荐阅读 / 相关人物 / 常见误读 / **年代异说** / 待核实 |

另有三个区域时间线、**世纪视图**（按世纪分桶，空世纪如实写「（此处空）」）、哲学家/概念/争论/流派四个索引、思想谱系总图（纯 SVG）、来源列表（核验状态标注）、比较视野 193 篇。

## 体例

- 每条论点、批评、引文、立场都标注 **原文**（原典有明确文本依据）或 **后人解读**（后代注疏与研究者的解释框架）。
- 引文只取能定位到篇目者，单条不超过一两句；查无出处的「名言」一律不用。**能核到原文之前，著作页一律不挂引文。**
- 每条内容至少两个独立来源互证，不足者标「待核实」并写明待核内容。
- 有实质争议处并列各方说法与依据，不替读者下结论，不贬抑任何一派。

## 缺口是公开的

| 文件 | 内容 |
|---|---|
| `DEBT.md` | 待核实清单（按 D72 口径统计） |
| `DEBT_CLASSES.md` | 待核实按「为何待核」分类：**结构性待核（无底本／无原典／并述即结论）** 与**可核者**分开 |
| `VERIFIED.md` | 已核记录（「已核（第 N 轮，据 source_id）：内容」） |
| `GAP_SCAN.md` | 年代空档扫描（按世纪分桶找出有结构的空白） |
| `THIN_WORKS.md` | 仅有 1 部代表作的哲学家 |
| `BACKLOG_SOURCES.md` | 待补来源及其**实测结果**（含 404 记录） |
| `BENCHMARK.md` | 同类项目调查（SEP／InPhO／PhilPapers／CBDB／ctext）与吸收/不吸收的清单 |
