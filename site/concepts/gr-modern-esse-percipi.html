存在即被感知 to be is to be perceived (esse est percipi)

首页 / 西方 / 近代理性论与经验论 / 概念

一、定义

贝克莱的核心命题：可感之物（色、声、形）皆是被感知的观念，而观念只能存在于感知它的心中；故“存在”即“被感知”。其要点并非否认世界，而是主张**世界的存在方式就是被感知**——由上帝的恒常感知保证其不被感知时仍续存。

二、在不同哲学家那里的用法差异

哲学家这里的用法
贝克莱（其立）以《三篇对话》立此命题；这一用法须与相邻概念分辨。
洛克（其先）其两种性质之说为其攻击的入口。
休谟（其后）承其现象论而悬置“心灵实体”。

三、一个具体例子

“存在即被感知”的要害是把**可感性质**与**心**绑死：既然色声只是观念，而观念只能在心中，则“脱离感知的物”不可设想。其力量在于它把洛克“两种性质”的逻辑推到底（贝克莱的刀正砍在洛克自己的分界上）；其困难在于“上帝”这一步：若无神，则物的续存无从保证。—— 贝克莱

出处/语境：《三篇对话》第一篇
