古路与新路 via antiqua / via moderna

首页 / 西方 / 中世纪经院哲学 / 概念

一、定义

中世纪晚期大学中的两条学术路线：古路（via antiqua）以实在论（司各脱、阿奎那的追随者）为宗，新路（via moderna）以唯名论（奥卡姆一系）为宗。它既是哲学立场的分野，也是**教师聘任与学位授予**的制度分野。

二、在不同哲学家那里的用法差异

哲学家这里的用法
奥卡姆的威廉新路（现代路线）的奠基：以个体为唯一实在，共相只是符号。
司各脱古路（精细博士）一系，主张共相有其“共同本性”。
大学制度（背景）两条路线各有其教师席位与学位要求，故争论兼有制度性。

三、一个具体例子

“古路/新路”的命名本身值得注意：把唯名论称为“现代”（moderna）在当时是**贬称**（新即可疑），后来才成为时代之名（“现代”由此进入历史语汇）。故一个哲学术语可以变成历史分期的名称。—— 奥卡姆的威廉
