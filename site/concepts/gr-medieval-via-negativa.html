否定神学 via negativa

首页 / 西方 / 中世纪经院哲学 / 概念

一、定义

伪狄奥尼修斯（托名）所传的神学方法：对上帝只能以**否定**言说——不说“上帝是善的”，而说“上帝非如此这般的善”；肯定之路（via positiva）须被否定之路超越，最终归于“神圣的黑暗”（mystical theology）。

二、在不同哲学家那里的用法差异

哲学家这里的用法
伪狄奥尼修斯《神秘神学》：在一切肯定之后须以否定超越之，最终“不知”而与之合一。
阿奎那（采纳并限制）以否定神学说明上帝之名的限度，但仍主张“存在”之名最为恰当。
库萨的尼古拉（承之）以“有学问的无知”发展之：知自己的不知即是最高的知。

三、一个具体例子

否定神学的悖论在于它**必须言说不可言说者**：故其语言只能是“否定—超越”的运动，而这一运动本身即是接近的方式。伪狄奥尼修斯由此说，神学最终是“赞美性的沉默”。—— 伪狄奥尼修斯

出处/语境：《神秘神学》第4—5章
